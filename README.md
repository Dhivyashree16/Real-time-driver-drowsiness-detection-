# Real-Time Driver Drowsiness Detection

## Description
Real-time driver drowsiness detection system using Computer Vision to detect driver fatigue through eye and facial analysis and provide instant alerts for safer driving.

## Features
- Real-time face detection
- Eye monitoring
- Drowsiness detection
- Audio alert system
- Live webcam monitoring

## Technologies Used
- Python
- OpenCV
- Dlib
- NumPy
- imutils

## How to Run

```bash
python drowsiness_detection.py
```
