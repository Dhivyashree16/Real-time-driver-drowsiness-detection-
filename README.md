# Real time driver drowsiness detection

## Description

Real-time driver drowsiness detection system using Computer Vision and MediaPipe to detect driver fatigue through eye and facial landmark analysis and provide instant alerts for safer driving.

## Features

* Real-time face detection
* Eye monitoring
* Drowsiness detection
* Audio alert system
* Live video feed
* Web dashboard
* Real-time status updates

## Technologies Used

* Python
* Flask
* OpenCV
* MediaPipe
* NumPy
* HTML
* CSS
* JavaScript
* Winsound

## How to Run

```bash
python app.py
```
